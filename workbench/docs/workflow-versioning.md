# 工作流另存为新版

“另存为新版”创建独立工作流，保留原版及其历史。它适合在已经验收的流程上升级节点设置，也可以关闭升级选项，创建普通副本。此操作不启动运行、不生成业务产物，也不自动将原版移入回收站。

## 操作步骤

1. 从看板打开需要复制的正常工作流。先应用或取消节点属性、工作流名称和组合内部修改，并确认已保存到看板。
2. 点击顶部“另存为新版”，输入新版名称，检查重构预览。
3. 根据需要保留或关闭下列选项，再点击“创建新版”。保存成功后进入新版，原版仍保留。
4. 打开新版的输入准备区，检查已填写资料并重新预检。通过后再运行；新生成的图片仍需审核。
5. 确认新版已保存且满足需要后，返回看板，在原版卡片“⋯”中选择“移入回收站”。恢复与删除规则见[工作流生命周期](workflow-lifecycle.md)。

| 选项 | 作用 |
| --- | --- |
| 登记工具预设来源 | 将未登记来源的已注册工具记录为相应内置节点预设的固定版本。保留现有实例的配置与端口，不用模板覆盖自定义设置。 |
| 增加输入校验 | 根据结构化输入的必填字段，增加存在、类型和非空检查。文件是否存在、扩展名、内容及来源匹配，仍由资料预检与专业工具核验。 |
| 保存审核后阶段成果 | 从人工审核节点增加独立阶段输出，保存本次已审核回执或成果清单引用，不重复导出图片。原审核到下游能力的直接连接保持。 |
| 保留已填写输入资料，但需重新预检 | 将当前用户填写的资料按新输入节点映射复制到新版输入草稿。预检结果及运行放行不复制；文件变化后会重新检查。 |

前三项默认开启；全部关闭可只复制工作流定义。“保留已填写输入资料”可单独选择。预览会列出新版节点和连线数量、登记的工具预设、增加的校验与阶段输出，以及保留的固定 Skill 和学习目标数量。

如果目标是像用户一样通过聊天重构流程，应关闭前三项，先取得普通副本，再到聊天框描述要求、审阅并应用 AI 修改。自动升级选项用于一般版本维护，不能代替实际对话搭建与反馈的体验验收，操作方式见[工作流对话](workflow-conversation.md)。

## 新旧版本的关系

新版的工作流、节点、边和内嵌流程使用新 ID；人工审核的修改目标、学习改进目标及内部输出投影对应重映射。Skill 引用与固定内容版本保持，原并行依赖、资源设置和业务端口保留。专业能力仍派生自基础节点，工具预设负责保存可复用配置。

运行记录、历史消息、审核决定、反馈学习批次、已通过预检和定时任务均不复制。旧版已经完成的业务产物仍属于旧运行，不能当作新版运行完成或批准的证据。新版不会自动启动定时执行。

明确选择的已完成来源目录仍可作为新流程的输入。例如，指南可以导入旧四文件流程真实完成并审核的回执；将旧流程移入回收站不删除该运行或产物。导入仍检查来源运行、当前尝试、文件 SHA 和真实审核内容，不能用目录名称代替核验。

## 保存与恢复

弹窗先读取看板中的已保存原版，并与当前画布核对；创建前再次检查原版 revision。画布未保存、存在未应用草稿、编辑冲突、处于只读状态或组合内部编辑时，不允许创建。创建期间切换到其它工作流或返回看板，迟到的保存结果只保留在看板，不强行切换当前页面。

新版候选在预览时分配身份。修改名称或选项不会另换一个工作流 ID；提交后候选固定。保存结果不确定时，点击“确认保存结果”读取同一新版；如果暂未查到，可以单独重试创建同一个候选。不要通过重复打开空白流程来代替保存确认。若已经保存但打开失败，按钮仅重试打开，不再次创建。

## 业务链边界

“另存为新版”不会强行把专业节点链封装成组合。当前学习控制器按外层 Skill ID 定位，HDK 来源回执、Skill 计划和人工审核也要求本次运行中的明确生产节点与直接消费关系。保留这些连接，才能继续追踪反馈和真实产物。组合限制见[节点体系](workflow-node-system.md)。

首次打开新版可能以 100% 视图显示较大的画布，使用“适应画布”查看完整拓扑。自动取景可继续改进，当前已有手动入口。
