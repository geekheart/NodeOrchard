# 工作流文件夹与便携包

每个工作流拥有固定目录 `<workspaceRoot>/workflows/<workflowId>/`；默认工作区下对应 `workflow/workflows/<workflowId>/`。节点编辑器的“打开工作流文件夹”直接打开当前工作流目录。目录使用稳定 ID，流程改名不移动文件或改变历史引用。

数据库继续承担运行索引、并发版本和操作回执；工作流文件夹保存完整可携副本及相关资料。流程定义和聊天通过软件保存，目录中的运行快照、回执和文件不能替代数据库中的审核决定。总控主题与其他工作流聊天仍各自隔离。

## 目录内容

| 路径 | 内容 |
| --- | --- |
| `workflow.json` | 保存的工作流定义、修订和管理状态 |
| `conversation.json` | 当前工作流完整 AI 对话记录，不受界面最近消息显示条数限制 |
| `inputs/` | 工作流使用的输入素材副本，新运行绑定本目录中归属明确的资料 |
| `runs/<runId>/` | 新运行的执行原件、节点尝试、回执和中间文件 |
| `outputs/` | 默认交付副本；流程明确指定的其他交付位置继续保留 |
| `skills/` | 与历史运行关联的冻结 Skill 资料，不包含全局安装环境或认证 |
| `history/` | 冻结运行、文件登记及其他历史快照；迁移错误和导入来源证据也保留在这里 |
| `files.json` | 已归集文件的来源、包内相对路径、大小及 SHA 映射 |
| `workflow-package.json` | 导出时生成的包格式、文件校验和依赖说明 |

普通保存更新定义和对话，并按输入绑定指纹在后台归集输入素材，状态记录在 `history/input-sync.json`。资料归集只读取当前工作流已登记的输入、产物、运行和冻结能力，不扫描整个用户目录、其他会话或 Hermes 认证目录。目录里的额外普通文件也属于导出范围；链接不能用来引入目录外内容。

## 已有工作流迁移

启动时为已有工作流补齐目录并复制可确认的相关文件；旧原件、数据库记录、运行快照中的绝对路径和产物 SHA 保持原样。迁移不会启动节点、模型、学习或重新批准审核。打开目录只等待当前工作流的输入归集请求，不等待其他工作流的大批量资料归集；当前输入归集失败时仍打开目录，并明确提示素材未完全归集。

旧文件缺失、已变更或无法安全读取时，迁移记录具体错误并保留现有流程与聊天。完整导出会重新核对资料；缺少应有文件时拒绝打包，而不会把不完整副本标为完整备份。应先找回资料或明确修正相关引用，不能通过改写历史哈希消除错误。

新运行默认写入自身 `runs/`，输入复制到自身 `inputs/`，交付副本默认写入自身 `outputs/`。旧外部运行根继续用于访问历史原件；迁移复制成功也不构成删除旧原件或改变原审核身份的授权。

## 导出与导入

编辑器的主导出先应用当前未离开输入框的属性草稿，确认工作流保存修订，再归集文件夹并生成标准 ZIP32 文件，下载后缀为 `.workflow`。`workflow-package.json` 对包内文件记录 SHA；文件在打包中变化或修订已过期时，导出失败并保留当前草稿。不能把 JSON 改名为 `.workflow` 当作成功导出。

主导入只接受 `.workflow`，读取实际 ZIP 内容并校验清单、哈希、路径和大小。解包先进入暂存目录；验证成功后原子登记到工作区的新工作流目录，再载入编辑器。导入始终创建新副本，包括同名或来自同一工作流的包，现有流程和当前草稿保留。

同一次导入请求绑定稳定操作 ID 和文件内容摘要。网络中断导致结果未知时，使用原请求重试会读回同一个副本；内容不同的文件不能复用该身份。导入成功但载入失败时，重试只打开已登记的副本，不重复解包或创建。

导入为工作流、运行、产物和对话轮次重新建立身份，并重定位已登记的资料路径。聊天正文保留，历史操作卡的应用、审核、重试等活动入口剥离；导入的历史运行只读，不继续旧审核、重跑、学习或交付。需要体验结果时，针对导入后的当前定义明确发起新运行。

节点编辑器另保留“兼容 JSON 草稿”，仅导入流程定义；浏览器草稿冲突时的 JSON 备份是单独的恢复入口，均不代表完整文件夹备份。

## 依赖、权限与限制

包携带工作流相关文件及冻结能力资料；SDK、解释器、第三方库、已安装 Skill、模型提供商和认证仍由目标机器的实际环境管理，不打包全局安装或凭据。已登记素材路径可以重定位；代码字符串里硬编码的本机路径不作盲目替换，导入后仍需核对实际依赖与路径。

独立助手的工作文件夹固定为当前工作流目录，总控保留既有工作区和人工权限范围。只读 `workflow.folder` 返回获准工作流的目录、输入归集与迁移状态及导出地址；读取状态或地址不触发归集、打包或打开窗口。导入和本机“打开文件夹”由界面触发，助手没有相应写入或本机打开工具。导入文件和历史内容不会扩大会话权限。

当前 ZIP 限制为压缩文件 256 MB、累计展开 512 MB、单文件 128 MB、最多 10000 个条目。包只接纳受支持的普通文件和目录，拒绝越界路径、链接、重复路径、加密或不支持的 ZIP 结构；解压大小和校验不依赖压缩文件自报的值。限制以 `src/workflows/workflow-zip.mjs` 的实际合约为准。
