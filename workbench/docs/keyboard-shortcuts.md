# 快捷键

设置 → 快捷键提供操作、生效范围、当前组合及修改操作。点击“修改”后按下新组合，Esc 取消；可禁用单项、恢复单项或全部默认。编辑只改变本地草稿，点击“保存快捷键”后各页面即时使用；失败保留草稿。相同范围及有重叠的范围不能重复分配组合，系统或浏览器保留组合不可分配。

| 操作 | 默认组合 | 生效范围 |
| --- | --- | --- |
| 发送消息 | Ctrl+Enter / ⌘+Enter | 工作流、总控和任务对话输入框 |
| 聚焦对话 | Alt+Shift+M | 当前有对话的页面 |
| 显隐工作流对话 | Alt+Shift+C | 已加载工作流的编辑器 |
| 保存 | Ctrl+S / ⌘+S | 工作流编辑器，含属性输入框 |
| 撤销 | Ctrl+Z / ⌘+Z | 工作流编辑器，文字输入时使用原生撤销 |
| 重做 | Ctrl+Shift+Z / ⌘+Shift+Z / Ctrl+Y / ⌘+Y | 工作流编辑器，文字输入时使用原生重做 |
| 全选、复制、粘贴节点 | Ctrl或⌘ + A / C / V | 节点画布 |
| 创建节点副本 | Ctrl+D / ⌘+D | 节点画布 |
| 删除选中节点或连线 | Delete / Backspace | 节点画布 |
| 适应画布 | F | 节点画布 |
| 显隐节点库 | L | 节点画布 |
| 显隐节点属性 | P | 节点画布 |
| 快捷键帮助 | Shift+/（?） | 节点画布 |

Enter 默认换行；键盘录制、输入法组合及按键长按不会触发发送或编辑命令。按钮、端口的原生 Enter／空格激活，方向键移动、Shift 加速、空格拖动画布和 Esc 取消保持原有交互。未加载、关闭画布、非活动编辑器、只读和弹窗继续服从已有边界。发送繁忙、空白和只读消息时不会重复提交；快捷键不会直接批准审核、运行工作流或删除工作流。

前后端通过 `shared/keyboard-shortcuts.mjs` 共用真实操作目录和校验。偏好只保存绑定数据，不能提交任意函数、脚本或未知动作；旧偏好没有快捷键字段时使用默认值。保存其他偏好保留绑定，绑定更新保留其他偏好。助手通过已有设置只读投影获知当前组合，没有改键工具。浏览器或操作系统优先截获的按键不会由网页接管。
