# 工作流对话

对话是编辑器的操作入口；画布、固定运行快照和产物记录仍是执行事实。现有正式工作流不需要修改节点才能使用对话。

## 页面与使用

- 画布居中，右侧工作流对话支持拖动边界调整宽度；节点属性按需以抽屉展示，底部运行详情保留。
- 每条工作流保存独立会话。默认展开最近一轮问答，历史轮次可展开。未解决的审核、失败和待应用方案单独提示，折叠历史不会隐藏审核阻塞。
- 选中节点，或从产物卡点击“反馈此产物”、审核卡点击“在对话中回复此审核”，将对象带入输入框。消息发送时固定工作流、运行、节点尝试和产物身份，切换选择不会修改已发送消息的对象。
- 修改范围包括对话咨询、搭建／修改流程、重做本次产物、记录反馈、改进 Skill。明确的“通过”“需要修改：具体意见”“停止审核”可直接处理已选中的精确审核版本；没有明确对象时先选择对应审核卡。
- 运行使用原有输入准备和预检。新流程仍需填写输入，缺少资料会提示补齐。

## 对话搭建流程

Hermes 使用创建规划会话时的默认提供商与模型，在无工具、记忆只读的规划会话中生成添加节点、配置属性、连接端口、移除节点／连线和改名操作。模型、认证、端点与 fallback 由 Hermes 管理，切换默认选择不改写已有会话。每批操作由与手动编辑相同的模型函数验证，整批成功才应用；不接受直接替换整个流程的 JSON，不直接执行生成的代码。规划提示包含各类型的准确配置字段；无效候选最多自动修复一次（总计最多两次模型调用），失败则停止并保留原画布，连接失败和取消不自动重试。

画布变更先展示摘要，点击“应用节点修改”后形成一条可撤销记录。相机移动不影响方案，节点或配置变化会使旧方案失效。内部组合编辑、未应用的属性草稿、其它窗口冲突和只读流程均阻止方案应用。应用回执使用稳定 ID 在服务器独立复算，不以模型自述判断是否成功。

运行、审核和学习是独立操作；模型提出节点方案不授予这些操作的权限，也不代表流程已经运行或通过验收。

## 从已有工作流进行实际对话重构

需要保留正式版和历史时，先在看板打开原版；已归档的原版先恢复。使用“另存为新版”创建普通副本，关闭登记预设、增加校验和保存阶段成果三项自动升级选项，仅按需要保留已填写输入资料。这个步骤只创建独立编辑起点；后续重构要求在聊天框提出。

在“搭建／修改流程”中描述目标，例如：

> 先检查我准备的工程、正反面照片和必要资料是否齐全，缺少时说明要补什么；图片审核通过后保存阶段成果。保留现有工具、Skill 固定版本、审核和学习目标，不运行工作流。

等待提案后，检查新增节点、字段规则、连线及作用范围，再点击“应用节点修改”。规则不足、修改范围不对或展示有问题时，继续在同一聊天框反馈具体缺口，审阅下一轮修改。可以使用“自动布局”和“适应画布”检查节点及端口，应用后的图仍可手动编辑和撤销。

复制时的自动升级功能可供一般版本维护使用，但不能用它代替这条实际对话路径，再声称已经测试了用户描述、AI 提案和反馈修改的体验。事后只读重放已应用操作、核对应用回执和保存定义属于验收证据，不是搭建入口。

输入卡中的文件、文件夹和图片字段优先显示，既能看文件名，也能检查和编辑完整路径。画布缩略图集中在关键产图／修改能力和人工审核节点，最终交付保留成果总览（最多 4 张）。汇总、验收、导入等中转节点和仅保存阶段清单的输出不重复铺图，文件仍可从运行详情查看。最终输出没有运行时保留明确占位；所有图片仅来自所选真实运行。查看旧流程的图片应选择对应旧运行，不将其关联为新副本的已完成或已批准结果。

业务重构保留同次运行回执、Skill 计划和人工审核的直接连接；不能为了收拢画布而跨父子运行封装这些凭据链，或把外层学习目标藏进当前控制器无法定位的内部流程。输入草稿可复制，预检、运行、学习和审核必须分别建立新记录。


## 审核、重做与反馈

审核／重跑在后端检查用户回复对应的节点尝试 ID 与产物 SHA，并在异步文件校验后再次检查。旧版本回复不能批准后来生成的版本。组合内部审核只允许通过真实父子运行及嵌入流程身份追踪；不能附带其它工作流的运行。

“重做本次产物”使用固定运行快照和原输入，仅重跑选定节点及其下游。修改要求传给对应能力，Skill 正文和代码保持原版本。确定性工具是否支持文字要求取决于工具适配器；要改变工具配置或代码，请使用“搭建／修改流程”。

任意流程、节点和产物都可保存反馈。反馈记录不自动训练。显式改进 Skill 沿用已有候选与验证机制；选中一个 Skill 时，使用单独的定向反馈范围，只为它生成候选，其余 Skill 保持原执行版本。选中工具／产物时，仅能沿拓扑解析到唯一、明确允许改进且已完成的最近上游 Skill；目标不唯一或不在学习支路许可范围时，提示选择具体 Skill。新候选不能冒充已验证或已应用版本。

旧失败或不用的方案可以“结束此事项”，原消息和历史保留。等待中的人工审核必须作出真实审核决定，不能通过结束对话绕过。

## 持久化与隔离

会话保存在 SQLite，消息提交和动作具备幂等标识，刷新可恢复。服务重启将未确认的生成／操作标为中断或结果未知，不自动重放模型调用或外部操作。

规划上下文不传运行输入、输出、产物内容或学习样例；学习与验证运行不能作为普通执行反馈或局部重跑对象。执行模式原有 Hermes memory 更新机制和 Skill 固定版本机制保留。
