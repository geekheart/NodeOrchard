# 总控原生 Hermes 会话

普通总控主题使用持久 Hermes Agent 会话。Hermes 负责对话历史、原生工具调用循环、Skill 发现、记忆、上下文压缩和可用工具选择；工作台提供界面、主题身份、应用工具及人工权限。独立工作流助手和来源绑定的只读总控诊断仍使用受限应用编排，保持当前工作流范围。

## 一轮对话

1. 服务端绑定总控主题、人工消息、权限版本与固定模型路由，加载或恢复该主题的原生会话。首次接入旧主题时只传有界历史作为资料，完整旧记录仍按身份读取；不搬移、删除或重写原消息。
2. AI 在同一次原生工具循环中先报告本轮意图，服务端验证受支持的类型。普通咨询、搭建、反馈和诊断分别处理；意图本身不授权写入、运行或审核。应用工具在确认意图及权限后执行，不再为每个工具决策另开控制会话。
3. Hermes 继续原生工具调用，应用工具通过 stdio 回到现有 schema、dispatcher 和对象／版本校验。模型不能提供服务端角色、权限范围或其它主题的执行身份。工作流修改仍生成候选，用户应用和业务运行沿用原入口。
4. 原生流事件和应用工具回执投影到当前主题。用户停止会中断该次处理；断连、重启和结果未知均不自动重发。再次交流恢复原会话，已完成的动作通过持久回执核对。

旧聊天只在首条原生消息中作为只读背景引入，此后通过 `conversation.history` 分页读取原正文。原生文件和图片通过 `conversation.artifact` 交付为聊天附件，按主题、轮次和 SHA 固定到沙箱外的副本；停止、归档或源文件后续变化不改写已交付内容。诊断截图由宿主复核后传递图片字节，使用 Hermes 原生多模态工具结果；提供商不支持工具图像时，原生回退提供隔离目录内的图像，须实际读取后判断。

主题新建、归档和恢复继续由用户操作。归档只读，恢复后才可继续发送；归档不启动会话或重放动作。已有聊天、工作流、运行、产物和审核身份保持原样。

## 原生能力与实际就绪

总控继承本机兼容 Hermes 版本的 Agent 实现和已配置能力，而不是复制一套工具规划器。原生文件、终端、代码、Skill、记忆及子代理运行在同一个受约束进程树中；工作台原有日志、工作流、聊天引用和受控源码操作作为额外工具提供。

工具发现仍以 Hermes 真实注册、依赖检查、用户配置和当前策略为准。模型认证不自动提供图片服务、浏览器驱动、远端 MCP 或付费工具额度；工具在目录中出现也不证明具体业务已经成功。原生支持、本机就绪、协议验收和业务产物验收分别报告。

本版本保持以下限制：

- 定时、连接／认证管理和会修改运行环境的原生管理入口不用于绕过人工设置；工作流定时仍通过已有人工入口配置。
- 本地 TCP／Unix 服务和桌面驱动不因 Hermes 支持就自动可用。stdio MCP 子进程继承隔离，公网远端工具通过受控出站代理访问；依赖本机 daemon、私有网络或宿主桌面的能力明确报告当前不可用。
- Skill 读取与生成遵循私有 profile 的目录策略；原安装目录、内置来源与只读快照保持保护。总控产生的记忆和新 Skill 不直接修改 Hermes 原始共享资料。
- 原生迭代和工具自身限制继续由当前实现决定。工作台不给普通模型等待偷偷增加首响应、流空闲或整轮截止，手动停止、连接错误及上游终态仍生效。

## 进程、文件与网络隔离

总控使用独立 gateway 进程和专用 Hermes profile；不将现有工作流执行 gateway 的助手保护直接移除。配置、环境文件、已有技能和用户插件以受控只读快照继承；既有记忆只在初始化时复制，此后独立维护。会话状态、记忆、生成 Skill、缓存和产物仅写入该总控的私有运行目录。

认证使用私有副本，允许 Hermes 刷新自己的 OAuth 缓存，不写回原 Hermes HOME。人工重新登录和全局配置仍在 Hermes 完成；宿主准备新的快照时复核来源与当前会话身份，不把 AI 修改私有认证缓存视为应用权限变更。配置快照保持只读，不能通过重命名其父目录、硬链接或子进程修改来绕过策略。

macOS Seatbelt 约束整个原生进程及所有后代。启动前必须实测私有目录可写、外部读写受限、可读源码不能经硬链接写回、子进程继承限制，以及工作台端口不可连接。只有内核探测确认后才启动原生处理；不可用的平台或策略明确返回 `unavailable`，不降级为宿主直接执行或偷偷改走旧总控。

原生进程不能直接读写工作台数据库、用户工作流或原 Hermes 私有目录；业务证据按人工权限经应用工具读取。源码写入仍仅由用户手动开启 `supervisor.sourceRepair` 后使用宿主端受控工具，沿用预期 SHA、操作身份、记录、测试和回滚。原生终端不能绕过此开关，权限设置不进入工具目录。

出站网络只连宿主管理的代理，代理拒绝本机、私有、保留和不可确认的目的地址，并核对解析后的实际目标。原生进程不能直连系统代理或本机工作台 HTTP 接口；连接模型与公网工具不授予工作台管理权限。服务端应用工具走绑定主题和轮次的 stdio 回调。

## 维护与验收

修改该链路时通过原生会话及应用工具的真实接口验证：同主题连续上下文和重启恢复、主题隔离、归档只读、意图先行、权限变化、停止／断连无重放，以及原生工具和应用工具都可执行。隔离验收必须覆盖文件、子进程和网络拒绝，失败不得开放能力。

默认使用隔离数据和临时素材，保持用户真实工作流和认证不变。真实 Hermes 验收另行记录模型及已配置工具，可能消耗模型额度；测试桩和内核探测通过不冒充真实模型或业务执行成功。新增或变更的能力同步回写[能力目录](application-assistant-capabilities.md)、相关协议和同接口回归。
