# HDK 学习契约与本地资料边界

本目录只发布 `input.schema.json`、`plan.schema.json` 和本说明。它们是通用输入／输出契约，不代表一次真实学习或工程验收已经完成。

实际训练集、验证答案、来源清单、评分、候选 Skill、release gate 和历史运行都是本机数据，由 Git 忽略。新资料优先保存在项目根目录 `workflow/`；旧记录保留原路径，避免破坏归档引用。原个人命名学习说明保留在本机 `workflow/history/`，不随源码发布。

业务链面向执行，学习支路明确指定对比产物、评价规则与允许改进的 Skill。执行模式固定 Skill 并跳过学习支路；训练／验证使用同批只读记忆策略，验证输入与结果不进入优化提示。

公开测试使用 `test/` 中的脱敏 fixture，不依赖本机答案或把旧 release gate 当作新产物通过证据。工程能力边界见 [架构说明](../ARCHITECTURE.md)。
