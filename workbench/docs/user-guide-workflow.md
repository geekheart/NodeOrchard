# 板卡使用指南工作流

使用指南采用执行主链与可选学习支路。执行主链为：工程与正反面照片 → 事实核验 → 接口标注规划 Skill → OpenInterfaceMark 标注与 DrawIO 功能框图 → 人工图片审核 → 中英文指南编写 Skill → Markdown 与资源打包 → 来源、资源和双语验收 → 输出。需要并行处理的标注与框图可按依赖拆分；执行模式跳过产物对比和 Skill 改进支路。

## 输入与能力边界

通用输入包含 `sourcePath`、`productCode`、`hardwareVersion`、`releaseDate`、正反面照片、经当前工程绑定的技术资料，以及固定提交的 BSP、SDK 仓库。板级配置、参考答案和实际工作流由使用者在私有工作环境中准备，不随源码发布。当前 DAG 输入和具名端口见[指南 v2 能力合同](guide-dag-v2.md)。

照片区域必须由实际看图与原理图共同核对，绑定精确图片 SHA-256、已有器件位号和全局唯一区域 ID。首次支持另一块板或更换照片，需要重新核对区域与校准。照片与工程不完全一致时保留明确图注，网络和物理引脚以当前源工程为准。当前流程不会把未经核对的图像识别结果当作可靠接口位置。

接口标注 Skill 决定简洁的中英文标签和受限样式；固定工具负责几何变换、字体测量、排版及 OpenInterfaceMark 导入导出。指南 Skill 编写说明段落；固定工具从当前工程生成引脚表、文件引用、BSP 命令和验证范围。两项 Skill 均为小能力，不承担工艺填写、固件开发或电路修改。

## 学习和执行

目标 Markdown 只进入评估与 Skill 改写上下文。执行作者节点接收工程事实，不读取目标正文。已知答案的文件路径和内容哈希在预检中禁止作为普通技术资料输入；相邻目标 PDF 同样隔离。

学习使用 Hermes 的同批次只读记忆快照，不更新长期记忆，也不读取外部记忆。验证集输入、输出和反馈不进入优化提示。普通执行允许沿用 Hermes 的记忆更新机制，并固定 Skill 版本。

评估保留两层证据：固定工具检查文件、章节、资源、命令、物理引脚、标注与 DrawIO 实际导出；模型比较生成说明与参考段落，评价解释深度、上手步骤和中英文一致性。模型评价属于估计，不能代替事实核验、实际看图或用户审核。只有硬性检查通过、目标条件满足且产物获批后，才能应用候选版本。

样例需区分训练集与验证集。同一块板的不同日期或视角可验证参数和布局一致性，不能代表独立硬件的泛化验证。学习与执行的详细隔离规则见[学习协议](learning-protocol.md)。

## 输出与复核

每次运行保留独立节点与尝试目录，实际路径以运行记录为准。权威原件与交付副本分开保存，默认交付副本位于项目根目录 `workflow/outputs/`，也可指定输出位置。历史串行兼容执行器保留原目录规则，不搬移既有结果。

指南成果包括：

- `<productCode>_User_Guide.md` 和 `_en.md`。
- `img/` 中的正反面照片、中文和英文标注 PNG、对应 SVG 和可编辑 `.oim.json`，以及框图、原理图、尺寸和 Pinout。
- `sources/` 和 `source-evidence.json` 中的事实、来源、哈希和明确提供的工程资料。
- `preview.zh.html`、`preview.en.html`，用于检查实际排版与图片。
- 验收报告和完整资源包；打包后重新检查相对链接、成员 CRC 与 SHA。

标注工具固定使用 OpenInterfaceMark 提交 `f8f92636b2eb87ac956997e77c9239cf483913fc`。在独立本地浏览器上下文导入绑定项目，读回一致后才导出，禁止把工具示例当作产物。中文和英文文档各自引用对应语言的实拍标注图，保留与原理图一致的真实位号；器件框和引线需人工检查。

原始照片保留不变；文档插图可进行确定性的等比例缩放、旋转与添加白边，坐标须同步变换并记录来源。机械说明区分 PCB 轮廓和 STEP、装配体包络，不把焊盘总数当作信号触点数。生成指南不会连接硬件或烧录，也不能宣称实板测试通过。

### DrawIO 功能框图与双面 Pinout

功能框图使用用户明确选择的原始 DrawIO 模板，依据当前工程事实替换内容，再由本机 DrawIO CLI 实际导出。中文、英文框图分别用于对应语言文档；功能框图不显示器件位号，实拍接口标注保留真实位号。布局、直线或直角连线和对齐情况须在审核时检查。

框图保留 `.drawio`、`.svg`、`.png` 和来源清单。`hdk/guide_drawio.py` 使用临时独立配置启动 DrawIO，不改动用户打开的文档；重读实际导出文件及内嵌可编辑图进行一致性核验。导出失败不会用另行手写 SVG 冒充 DrawIO 结果。芯片、模组和接口来自当前工程，不能复制参考板的频率、引脚数量或附件。

四文件流程提供正反面 Pinout 时，指南分别展示两面实拍标注，提醒翻面后按物理针脚编号定位，不能按屏幕左右推断针序。旧资料仅提供单张 Pinout 时保留单图兼容版式。

## 维护

实际工作流通过看板、节点属性和对话入口维护。修改能力、解析器、模板或 Skill 后，需用自己的资料重新运行并审核；既有运行的回执、固定版本与批准保留。运行结果的“反馈与改进”可记录问题，允许改进的范围由学习支路明确绑定的 Skill 决定。
