# 工作台统计

统计页使用主页面配色和深浅主题，通过连续读数、时间趋势、工作流比较表和选中项详情查看运行与用量。支持最近7天和30天，按 `Asia/Shanghai` 自然日划分。搜索、生命周期筛选和排序仅改变明细比较；顶部汇总保持所选周期的整体口径。

| 数据 | 来源与口径 |
| --- | --- |
| 工作流执行 | 全量 `workflow_runs`，不受最近20条列表限制；子流程归属根流程，根执行次数去重；学习样本执行计入实际运行并单独记录学习次数 |
| 成功率 | 成功 /（成功 + 失败 + 停止 + 待确认）；进行中不参与分母，空分母显示未知 |
| 运行耗时 | 有效开始、结束时间的差值；没有完成时间不当作零耗时 |
| 对话 | 独立会话与总控主题分开；总控按主题投影待处理状态，工作流复用现有事项关闭、重试和审核语义；历史失败尝试仍计入失败 |
| 模型与工具调用 | 对话已保存的诊断进度及模型会话归属；逻辑对话轮次不等于Hermes内部API请求次数 |
| Token | `run_usage` 中单次本地模型运行的用量差值，按运行开始时间归属日期；使用Hermes上报的input/output/total/calls，不把推理Token再次加总 |
| 上下文 | 所属模型会话最近一次上下文测量，显示采集时刻、来源和估算标志；不同会话的占用率不相加，模型窗口未知时不计算比例 |
| 登记产物 | 产物注册中的数量及size；缺少size单独计数，不声称等于实际磁盘空间 |
| 记录占用 | 已保存流程、运行、聊天及产物登记等结构化记录的字节数，作为当前累计快照，不等于SQLite文件或工作文件夹总大小 |

消耗统计包含回收站与已删除工作流的保留历史，避免删除流程后消耗消失；对话管理仍只展示正常工作流。总控助手及未关联普通会话的模型消耗独立归集，避免重复分配。冲突归属不能推断为任一工作流。图表由真实聚合值生成，没有观测数据时显示未采集。

## 用量采集

`SessionUsage` 订阅现有 `session.info`、`session.usage`、`message.complete` 数字字段；会话创建与恢复也保存受限快照。只写白名单数字、来源和采集时间，不保存提示词、认证或账户配额，不新增用量RPC。同一快照重复到达覆盖同一记录，不能累加累计计数。

`session_usage` 保存会话累计快照，`run_usage` 保存以 `runs.id` 为身份的基线与差值。明确新建的会话可从零开始；旧会话缺少基线时历史累计值不归给当前运行。计数回退按新代次处理，不能跨重置相减。缺少完整终态字段、连接中断或只有进行中快照时保留部分采集，不能冒充完整结果。采集异常不得改变执行、审批或取消结果。

覆盖分为完整、部分、缺失三类。显示的Token是已观测值；部分值可能低于实际消耗。历史没有采集的数据无法按时间精确还原，用未知值而非零表示。CPU、内存的逐工作流归属及订阅费用尚未采集，不推算付费价格。

## 接口与验证

`GET /api/statistics?days=7|30` 保留旧任务统计字段，新增 `dashboard` 投影。助手通过同一统计服务读取受权限约束的 `workbench.inspect`，不能写计量或修改权限。读取统计不创建会话、不恢复模型、不修改流程、不执行运行。

相关测试分别覆盖单次用量差值与恢复、全量去重与时间边界、事项投影与脱敏、HTTP及助手权限，以及界面空值、选择、排序、刷新和窄屏样式。验收仅使用隔离fixture，业务记录和真实运行保持原样。
