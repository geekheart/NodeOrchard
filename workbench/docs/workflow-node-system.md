# 工作流节点体系

节点分为基础节点、单节点预设、组合节点。现有四文件、Pinout、指南、HDK 专业能力保留为工具预设，不再与基础节点混排。节点颜色继续由基础类型的分类决定。

## 基础语义

共 14 类：输入／触发、校验、AI／Skill、工具／代码、子流程、数据整理、汇总、条件判断、逐项处理、条件循环、人工审核／补充、产物输出、产物对比、Skill 改进。后两类是学习支线，普通执行跳过。当前 AI／Skill 入口调用固定版本 Hermes Skill，不增加独立模型和记忆实现。

并行由依赖、运行并发上限和资源占用决定，不增加并行节点。手动和定时共用同一输入契约。现有重跑、人工修改反馈、来源核验和记忆隔离继续由公共运行机制管理。

校验节点用具名字段路径检查 required、nonempty、type、equals，通过后原样传递输入；失败保留每条检查结果、阻止下游，不调用模型。路径只能读取自身数据，不读取原型字段。文件存在性、扩展名和来源哈希仍由输入资料预检负责；板卡专用语义由对应工具校验器负责。

产物输出可以选择阶段产物或最终交付。阶段产物在节点完成时即保存，并可继续传递。运行记录的 outputs 保留全部输出，stageOutputs 单列阶段结果，output 汇总最终结果。旧文档没有显式用途时保留原有行为。图片预览支线不等于批准；生成图片仍须存在人工审核路径，未经审核不能流入生产能力或显式最终交付。

## 节点预设

预设是原始节点的配置快照，包含名称、说明、基础类型、端口、工具／代码或固定 Skill 引用。所有已注册工具都通过同一个元数据入口生成内置预设，包含原有端口、资源与强制图片审核属性。内置预设只读，可另存个人预设。

个人预设保存在 SQLite，并保存不可变版本。发布新版本采用 expectedRevision 比较并更新；老版本仍可读取，已有工作流实例保持原版本。拖入时创建新的实例 ID，递归重映射内部节点、审核目标和输出投影，避免两个组合共用标识。实例的 origin 记录来源 ID、版本、名称、种类和基础类型。

保存预设默认移除输入路径、输入字段默认值和输出根目录；代码和工具配置保留，保存弹窗明确说明。专业工具自身可能要求用户提前准备的板级配置文件，这些要求仍由输入契约及预检呈现。

## 组合与内部编辑

在画布中多选能力、数据、控制或人工节点，选择“封装为子流程”。系统根据选区的跨边界连线生成具名输入输出，允许修改端口显示名称；内部连接、类型和人工修改目标保留。外层是普通 subflow 节点，内部是普通工作流快照。

进入内部编辑使用独立暂存区。边界输入输出的身份、字段名和类型固定，内部能力与连线可以修改；应用后回写父流程，取消则恢复父流程原有历史和选择。内部编辑不创建独立看板条目、不保存成独立工作流，也不能启动运行、定时或学习。原有逐项和循环节点的固定内部快照也可进入编辑。

展开子流程时将内部能力映射回外层，并保留内部输出节点为阶段保存，避免丢失中间文件。外部人工审核修改目标重新定位到实际生产能力。工作流中的实例修改不会覆盖其来源预设，发布新版本需要显式操作。

## 明确限制及后续扩展

- 当前学习控制器以外层 Skill 节点 ID 为目标。已被学习节点绑定的 Skill，以及正连接外部产物对比的能力，暂不直接封装；界面说明原因，原来的四条业务学习支线继续可用。后续需要可版本化的内部节点路径及学习目标选择器，才能安全支持组合内部的 Skill 优化。
- 条件分支必须先在选区内汇总，不能把可能跳过的分支直接暴露成多个子流程输出；跨边界可跳过的可选输入同样明确拒绝。后续可增加显式“缺席值”传输协议，不能用 null 冒充未执行。
- HDK 工具的已核验回执绑定生产运行。元数据声明 runBoundInputs，封装不能把相互依赖的回执生产、消费或审核拆到不同运行中。可将完整相关链封装，或保持外层原有连接。后续需正式的父子运行来源映射和审核凭据传递，不能取消现有真实性检查来实现复用。
- 展开只支持能够映射到子流程最终输出的端口；额外字段投影会提示保留组合并进入内部编辑。逐项和循环保留控制语义，不提供直接展开。
- 执行中的子流程有原有父子运行记录及人工审核委托；本次不新增逐项并发实现，现有 foreach 仍按原顺序执行。独立分支的 DAG 并行保持。

这些限制在创建或展开时检查，不会等到消费模型额度后再静默改变行为。

新版可保留已填写的输入资料，但必须重新预检；运行记录、人工批准、会话和定时任务不随副本迁移。节点改动只改变工作流定义，不代表已经重新生成工程、图片、指南或固件。普通副本入口见[另存为新版说明](workflow-versioning.md)，通过 AI 描述要求、审阅和应用修改的操作见[工作流对话](workflow-conversation.md)。
